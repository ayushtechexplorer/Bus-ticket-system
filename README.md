# Introduction
Dynamic Online Bus Ticket Booking system with Passenger and Admin panel with different Algorithm implemented and CRUD operation

Online bus ticket booking system is a web-based project designed for reserving bus seats online using mobile payment. It provides a convenient platform for passengers to book tickets, check seat availability, and make payments from anywhere without visiting the bus station.The system also includes easy-to-use tools for authorized admins, allowing them to handle bookings, check bus schedules and routes, and manage passenger information to keep everything running smoothly and efficiently

# Feature
1) To allow passengers to book bus tickets online anytime and anywhere without visiting the bus station.
2) To provide instant updates on seat availability to avoid overbooking and ensure accurate reservations.
3) To integrate mobile payment options for fast, safe, and cashless transactions.
